# 🛡 Fake Product Detection System

A smart web-based application to detect fake vs genuine products using image processing, deep learning, and QR verification.

## 📌 Project Overview
This project uses Streamlit, OpenCV, and MobileNetV2 to verify product authenticity.

## 🚀 Features
- Product Registration with QR code
- Image-based Verification
- QR Code Verification
- Dashboard Analytics
- Edit/Delete Products
- History Tracking

## 🛠 Tech Stack
- Python
- Streamlit
- OpenCV
- TensorFlow
- SQLite

## ⚙️ Installation
1. Clone repo
2. Install requirements
3. Run: streamlit run app.py
